01 · 磁吸按钮

触发区固定在元素的静止位置，不随元素自身移动。这是避免「按钮追着鼠标抖」的关键。

嵌套：卡片与按钮各自磁吸
  • 触控设备上自动跳过（hover: none），不留半截位移。
  • 鼠标按下时立即释放，不与拖动抢指针。
  • 键盘聚焦只改描边，不移动元素 —— 移动焦点目标是无障碍事故。

04 · 惯性滚动

默认 native：不劫持滚轮，只做吸附辅助。切到 virtual 才接管，并同时补齐键盘、焦点、吸附。

native 0 / 0

吸附点 1

滚轮、拖拽、键盘 PageDown 都应该停在这里。

吸附点 2

在 virtual 模式下，输入框获得焦点会把自身滚进视野。

吸附点 3

系统开启「减少动态效果」时，virtual 会自动退回 native。

吸附点 4

内容不足一屏时引擎直接停用，不做无意义接管。
